# ADR 0002: Project license

- Status: accepted
- Date: 2026-09-11

## Decision

Seki-authored code and documentation are released under the GNU General Public
License, version 3 or (at the recipient's option) any later version:
`GPL-3.0-or-later`.

Third-party dependencies retain their own licenses. Dependency qualification
must separately determine whether acquisition, use, linking, modification, and
redistribution are compatible with Seki's intended delivery profiles. In
particular, this decision does not grant rights to CompCert.
